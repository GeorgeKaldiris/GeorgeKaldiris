**Python | PyTorch | Hugging Face | Qwen3-8B | FastAPI | Pydantic | Docker | pytest | GitHub Actions**

### 🛡️ Phishing URL Classifier API

**Python | scikit-learn | TF-IDF | Logistic Regression | FastAPI | Docker | pytest | GitHub Actions**

An end-to-end Machine Learning system for classifying URLs as legitimate or potentially malicious.

- Trained the model on approximately **150,000 URLs**.
- Used character-level TF-IDF features and Logistic Regression.

- Used decision-threshold tuning and stratified cross-validation.
- Saved the trained model and vectorizer as reusable inference artifacts.
- Exposed predictions through a FastAPI REST API.
